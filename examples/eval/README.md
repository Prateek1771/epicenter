# Measured eval runs

These are the RCAEval RE2-TT runs (`0002`–`0008`) and the synthetic-suite run (`0007`) that the README's results come
from, as `python -m api.eval` wrote them. `/eval` reads them when there's no local run in `data/eval/`, so a fresh clone
or the hosted demo shows the real numbers. A new local run takes precedence. `cases-re2tt.json` lists the 90 cases.
