## Bugs found and fixed

1. **`--download` of a case that doesn't exist** silently created an empty directory, then said "add --download".
   - Fix: only `logs.parquet` may 404; anything else raises "not on Hugging Face … check the case name" and exits 2.
   - Test: `test_download_of_an_unknown_case_fails_clearly`.
2. **The ask agent's path for "who should I page?" was one node**, because `who_knows` returned only handles.
   - Fix: `who_knows` returns `via` (MEMBER_OF / FIXED / AUTHORED) and the owning `team`. The ask agent may cite the
     ids it called a typed tool with, and the prompt asks for a path from the subject to the answer.
   - Live answer now: `checkout → OWNED_BY → payments → MEMBER_OF → pay-oncall`.
   - Tests: `test_who_knows`, `test_typed_tool_first_and_path_keeps_only_seen_ids`.
3. **The incident page defaulted to status "open"** before its data arrived, flashing a primary "Diagnose" button on
   diagnosed incidents. Fix: no pill or action until the status is known.
4. **Live alert → verdict was 62 s (N1 miss) on flip-commerce.**
   - Cause: every ingest, and every minute's topology tick, scanned all of `spans.jsonl`, the nginx log and the node
     logs from the top. That's 160 MB after a few hours, and it grows all day. This was a known `ponytail:` ceiling.
   - Fix: `otel.lines_since` binary-searches the byte offset (these files are append-only and time-ordered) and
     reads from just before the window.
   - On today's files: identical spans and logs (72 529 / 20 791), 19.2 s → 4.8 s. The next live run took 12.1 s.
   - Test: `test_lines_since_reads_only_the_window_of_a_long_file`.

5. **The slow-burn pass never saw its 6 h lookback** (found by the synthetic `mem` case: 0 anomalies).
   - Cause: `ingest_window` gave the pass the short window's series, which start ~12 min before the alert, so a
     climb that began hours earlier never reached the 1.5× ratio, in replay or live. The detector itself was tested;
     the wiring wasn't.
   - Fix: `Adapter.metric_series(start, end)` (RCAEval `metrics.parquet`, OTel Prometheus at a 1-minute step), and the
     pass fetches `[t − 6 h, t]` itself, as LLD §3.2 already said.
   - Test: `tests/test_synth.py` small `mem` asserts a `slow_burn` anomaly and the right verdict. `mem` is now found at
     small, medium and huge. The RE2-TT eval was re-run because this touches ingest (see below).
